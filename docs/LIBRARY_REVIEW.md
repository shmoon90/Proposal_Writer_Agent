# 문서 생성 라이브러리 검토 (Phase 16, 2026-10-16)

편집 가능한 산출물 요구(요청서 §10·§12)에 대해 현재 스택이 무엇을 지원하고 무엇을 지원하지 않는지 확인한 기록이다. 확인 방법은 설치된 패키지의 API와 이 프로젝트의 실제 생성 결과(python-pptx로 만든 덱을 PowerPoint에서 열어 편집)다. 지원하지 않는 기능을 지원한다고 가정하지 않는다.

## 1. PowerPoint — python-pptx (유지)

| 요구 요소 | 지원 | 이 프로젝트의 사용 | 비고 |
|---|---|---|---|
| 제목·본문 텍스트 상자 | 지원 (`add_textbox`, 문단·런·글꼴) | 모든 슬라이드 | 자리표시자(placeholder)도 지원 |
| 글머리표·주석 | 지원 (문단 수준, 글머리 문자) | 요점·※ 주석 | 들여쓰기 수준 제어 가능 |
| 표 | 지원 (`add_table`, 셀 텍스트·채움·테두리) | 요구사항 대응표·비교표·일정표 | 셀 병합 지원(`merge`) |
| 도형·연결선 | 지원 (`add_shape` 자동 도형, `add_connector` + 화살촉은 XML 추가) | 구성도·흐름·카드·화면 설계 10종(`shapes.py`) | 연결선 끝점 연결(`begin_connect`)은 도형에 붙일 수 있음 |
| 차트 | **지원** (`add_chart`: 막대·꺾은선·원·분산 등, 편집 가능한 네이티브 차트, 데이터시트 포함) | **미사용** — 현재 공수·일정·KPI는 도형 막대 | 20단계에서 네이티브 차트로 전환 |
| 그림 삽입 | 지원 (`add_picture`, 크기·위치·자르기 속성) | Phase 13 이후 덱에 미사용; 사진·일러스트는 태그로 허용(Phase 16) | 그림은 PowerPoint에서 선택·이동·교체·삭제 가능 |
| 그룹화 | 지원 (`shapes.add_group_shape([...])`, 내부 도형 개별 편집·그룹 해제 가능) | 미사용 | 20단계에서 도식 단위 그룹화 검토 |
| 글꼴·색·정렬 | 지원 | 템플릿 프로파일 값 적용 | 테마 색은 RGB로 지정 |
| 마스터·레이아웃 재사용 | 지원 (기존 PPTX 열어 레이아웃 선택) | 고객 템플릿 위 생성(Phase 12) | 레이아웃 삭제는 XML 조작 |
| 발표자 노트 | 지원 (`notes_slide`) | 소절 `speaker_notes` | |
| SVG 아이콘(편집 가능 벡터) | **미지원** (SVG 삽입·변환 API 없음) | 미사용 | 아이콘은 자동 도형 조합으로 대체 |
| 슬라이드 렌더링(미리보기 PNG) | **미지원** | 없음 | PowerPoint COM(아래)으로 보완 |
| 대량 슬라이드 안정성 | 수백 장 생성 문제 없음(파일 크기만 증가) | 제출용 18장·발표용 19장 | |
| 파일 호환성 | OOXML 표준 PPTX, PowerPoint 2016+ 정상 | 사용자 PowerPoint에서 열어 확인(2026-10-15) | |

결론: python-pptx는 텍스트·표·도형·연결선·차트·그림·그룹을 **개별 객체로** 생성하므로 편집 가능성 요구를 충족한다. 교체 시 템플릿 빌더·도식·QA 전부를 다시 써야 하므로 유지한다. 미지원 두 가지(SVG, 렌더링)는 아래로 보완한다.

## 2. 렌더링·재열기 검증 — PowerPoint COM (pywin32)

- 이 개발 PC: `PowerPoint.Application` COM 등록 확인, `pywin32` 설치 확인(2026-10-16). LibreOffice(`soffice`)는 없음.
- 계획(21단계): PowerPoint로 PPTX를 열어 슬라이드를 PNG로 내보내고(`Slide.Export`), 다시 열어 도형 수·글꼴·표를 비교한다. COM이 없는 환경(CI 등)에서는 해당 QA 항목을 **미실행**으로 기록한다(성공으로 표시하지 않음).
- 제약: Windows + PowerPoint 설치 환경 전용, 동시 실행 불가(단일 COM 인스턴스), 파일이 이미 열려 있으면 잠금 충돌.

## 3. Excel — openpyxl (유지)

| 요구 | 지원 | 사용 |
|---|---|---|
| 셀 데이터·서식·병합·틀 고정·필터·유효성 | 지원 | 정의서·추적표·WBS·투입계획 |
| 수식 | 지원 (문자열로 기록, 계산은 Excel이 수행; 캐시 값은 없음) | 투입계획 계/합계, 비용 |
| 차트 | 지원 (`openpyxl.chart`, 원본 데이터 범위와 연결) | 미사용 — 간트는 셀 채움 | 보조 Excel 차트가 필요하면 적용 |
| 읽기(재적재) | 지원 (`data_only=True`로 캐시 값) | 구축 단계 기준 문서 | 수식만 있고 캐시 값이 없는 파일은 값이 비어 읽힘 |

## 4. 다이어그램 PNG — Pillow (보조 산출물)

구성도·일정·공수 PNG는 `10_Diagrams_Charts_Images`에 별도로 남기며 덱에는 넣지 않는다(편집 불가). 보고서·요약용이다.

## 5. 정리

- 유지: python-pptx, openpyxl, Pillow. 추가 설치 없음(pywin32는 이미 있음).
- 보완: 네이티브 차트(20단계), 그룹화(20단계), PowerPoint COM 렌더링·재열기(21단계), 그림 태그 정책(16단계, 이 문서와 함께 적용).
- 하지 않음: SVG 아이콘 편집(대체: 도형 조합), LibreOffice 설치(사용자 환경에 없음), 기술 스택 교체.
