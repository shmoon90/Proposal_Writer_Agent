## 0. 원칙 (지시문 §0.3·§18)

- 기존 코드는 재사용·보강이 기본. 전체 재작성 없음. 대형 모듈 분할은 동작 변경 없이.
- 단계마다: 구현 → `pytest`(llm 제외)·`ruff`·`mypy` → 실샘플(계산기 + 실제 RFP fixture) 재실행 → 결과 기록(`DEVELOPMENT_STATUS`, `TEST_RESULTS`, `WORK_LOG`) → 커밋.
- 에이전트는 분석·검토에만 쓰고 계산·파일·검증은 Python. 새 역할은 입력/출력 스키마·도구·예산·검증 함수를 함께 정의.
- 승인 필요 항목(A-1~A-7) 은 해당 단계 착수 전에 묻는다. 되돌릴 수 있는 작업은 계획대로 진행.
- 품질 기준선(`QUALITY_BASELINE.md` §3) 보다 나빠지면 회귀로 보고 다음 단계로 가지 않는다.
